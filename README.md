### Опис проекту
Кросплатформний табличний процесор, розроблений на базі **.NET 8 MAUI** та патернів ООП (**Interpreter / Visitor** для обчислення виразів, **Observer** для оновлення інтерфейсу, архітектурний шаблон **MVC/MVVM**).

### Реалізований функціонал (Варіант 37)
- **Базова арифметика:** `+`, `-`, `*`, `/`, унарний мінус, коректні пріоритети операцій та робота з круглими дужками.
- **Специфічні функції варіанта 37:**
  - `max(x, y)` — знаходження максимуму з двох аргументів / виразів;
  - `min(x, y)` — знаходження мінімуму з двох аргументів / виразів.
- **Операції порівняння та логіки:**
  - `<=` (менше або дорівнює);
  - `>=` (більше або дорівнює);
  - `<>` (не дорівнює);
  - `not(x)` — логічне заперечення.
- **Порожні клітинки:** автоматично трактуються як `0` у числових виразах і не викликають збоїв обчислення.
- **Автоматична транслітерація адрес:** введення кириличних адрес (`А1`, `В2`) нормалізується в коректні латинські `A1`, `B2`.
- **Захист від циклічних залежностей:** надійне виявлення та запобігання зацикленню для прямих і непрямих ланцюжків залежностей (`#CYCLE!`).
- **Перерахунок у реальному часі:** автоматичний каскадний перерахунок всієї таблиці при виході з клітинки або рядка формул (подія `Unfocused`).
- **Динамічний розмір таблиці:**
  - Додавання та видалення рядків;
  - Додавання та видалення стовпчиків;
  - **Захист:** неможливо видалити останню клітинку (таблиця завжди зберігає щонайменше 1 рядок і 1 стовпчик із попередженням користувача).
- **Хмарна синхронізація:** збереження та завантаження таблиць у хмару **Google Drive** через Google Drive API v3 (OAuth 2.0).

---

### Налаштування Google Drive API
1. Скопіюйте файл `client_secrets.json.example` у `client_secrets.json`.
2. Заповніть ваші `client_id` та `client_secret` з Google Cloud Console.
